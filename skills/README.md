# Skills Directory

This directory contains reusable code skills that can be referenced by the solve memory system.

Each skill is stored as a separate markdown file with the following structure:

```markdown
## Skill: SkillName
- Tag: skill_tag
- Category: category_name
- Applicable_when: description
- Not_for: description
- Complexity: time and space complexity
- Pitfalls: common mistakes

### Snippet (C++17)
<code block>
```

Skills are referenced by solve memory items using `skill_id` and `path`.
